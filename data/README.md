# Data

Large public source datasets are intentionally **not committed to GitHub**.

Place the following files in `data/raw/` using the exact filenames below:

1. `2025HwyBridgesDelimitedAllStates.txt`
   - FHWA 2025 National Bridge Inventory
   - https://www.fhwa.dot.gov/bridge/nbi/ascii2025.cfm

2. `tl_2025_us_state.zip`
   - U.S. Census Bureau 2025 TIGER/Line State and Equivalent shapefile
   - https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html

The included file

`data/external/NOAA_nClimDiv_1991_2020_County_Climate_KS_MO.csv`

contains the county-level 1991–2020 monthly long-term climate averages used in the Kansas–Missouri climate sensitivity analysis. The file records the corresponding NCEI source URLs.

NClimDiv dataset DOI: `10.7289/V5M32STR`

Before estimation, `run_all.py` records SHA-256 hashes for the three analysis inputs in:

`results/generated/input_manifest.json`

Preserve this manifest with the frozen manuscript results so the exact input files used in the analysis can be identified.

Files under `data/processed/` are generated by the workflow and are not committed to Git.
